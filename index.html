QUESTIONS

Short answers.

What data do you collect? +

None. No birthdays, no names, no accounts, no tracking cookies, no analytics. The gate stores a single yes/no flag in the visitor’s own browser.

How is my choice remembered? +

On your device only, in localStorage, one key per age threshold. It never leaves your browser and no server ever sees it.

What age does it check? +

Whatever the site sets. The default is 21.

Where do I go after verifying? +

Wherever the site points you. Link mode appends #dogs-verified=21 so the destination knows the check passed.

Which browsers work? +

Any modern browser with JavaScript and localStorage enabled.
